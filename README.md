# Disease Dashboard

Лабораторна робота 1: каркас аналітичного дашборду про епідемічну статистику (COVID-19) на React. Дані поки що mock, їхня структура повторює відповіді API [disease.sh](https://disease.sh).

## Віджети

- **KPI Card**: один показник (заголовок, значення, добовий приріст). Перевикористовується для п'яти карток, повне число показується в підказці при наведенні.
- **Toggle**: перемикає картки між абсолютними числами та показниками на мільйон населення.
- **Counter**: степпер з кнопками «+», «−» і скиданням, зберігає число у власному стані.
- **Filtered List**: список країн із фільтром за континентом.
